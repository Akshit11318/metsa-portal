## 📦 What You Need After Cloning

### Required Environment Variables

#### Backend (`backend/.env`)
```bash
NODE_ENV=production
PORT=5000
DATABASE_URL="file:./dev.db"
JWT_SECRET=<auto-generated-by-setup-script>
CORS_ORIGIN=https://your-domain.com
CSRF_ENABLED=true
CSRF_SECRET=<auto-generated-by-setup-script>
DEFAULT_YEAR=2025
```

#### Frontend (`frontend/.env.production`)
```bash
VITE_API_URL=https://your-domain.com/api
VITE_APP_NAME=MetSA Portal
VITE_APP_DOMAIN=your-domain.com
```

### What to Change

**Before Deployment:**
1. Update `CORS_ORIGIN` in `backend/.env` to your actual domain
2. Update `VITE_API_URL` in `frontend/.env.production` to your actual API URL
3. Review and update `docker-compose.yml` CORS_ORIGIN if using Docker

**Note:** `JWT_SECRET` and `CSRF_SECRET` are auto-generated by `setup.sh`

## 🚀 Deployment Steps (Quick Reference)

### 1. Clone Repository
```bash
git clone https://github.com/Akshit11318/metsa-portal.git
cd metsa-portal
chmod +x setup.sh run.sh
```

### 2. Run Setup Script
```bash
./setup.sh
```
**This will:**
- Install all dependencies
- Setup database
- Create 5 admin accounts with strong random passwords
- Save passwords to `credentials.txt`
- Generate secure JWT and CSRF secrets

### 3. Save Credentials
```bash
cat credentials.txt  # View passwords
# Copy to secure location (password manager)
rm credentials.txt   # Delete after copying
```

### 4. Update Environment Variables
```bash
# Backend
nano backend/.env
# Update: CORS_ORIGIN=https://your-actual-domain.com

# Frontend
nano frontend/.env.production
# Update: VITE_API_URL=https://your-actual-domain.com/api
```

### 5. Start Application
```bash
./run.sh start
```

### 6. Change Default Passwords
- Login to each account
- Navigate to profile/settings
- Change password immediately

Quick version:
```bash
#!/bin/bash
BACKUP_DIR="/backup/metsa"
DATE=$(date +%Y%m%d_%H%M%S)

mkdir -p $BACKUP_DIR
cp backend/prisma/dev.db $BACKUP_DIR/db_$DATE.db
tar -czf $BACKUP_DIR/uploads_$DATE.tar.gz backend/uploads/

# Keep last 7 days
find $BACKUP_DIR -mtime +7 -delete
```

Setup cron:
```bash
crontab -e
# Add: 0 2 * * * /opt/metsa-portal/backup.sh
```
